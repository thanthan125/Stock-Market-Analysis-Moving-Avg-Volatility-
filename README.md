# Stock Market Analysis

This project performs time series analysis on stock price data including moving averages and volatility measurement.

## 🔍 Objectives
- Analyze stock price trend
- Compute moving averages (20 & 50 day)
- Calculate daily returns
- Measure stock volatility

## 📊 Features
- Moving average crossover visualization
- Volatility estimation
- Return analysis

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib

## 📁 Project Structure
- stock_analysis.ipynb → Main notebook
- stock_data.csv → Generated dataset
- requirements.txt → Dependencies

## 📈 Key Insights
- Moving averages smooth price fluctuations
- Daily returns help assess performance
- Volatility measures risk
